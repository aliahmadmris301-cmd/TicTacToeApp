#TicTacToe App
## Project Overview
This project implements a **console-based Tic-Tac-Toe game** where a human player competes against the computer.  
The application is developed using a **Use Case (UC) based approach**, demonstrating step-by-step enhancement of functionality.
---
## Objective
- Build a fully functional Tic-Tac-Toe game in Java
- Strengthen understanding of:
  - Logical thinking
  - Control flow
  - Modular programming
  - Object-oriented principles (basic level)
